# 🦷 Sastha Dental Clinic

**Quality Dental Care with Compassion, Expertise & Modern Treatment**

Welcome to the official website repository of **Sastha Dental Clinic**, a trusted dental care provider in Chennai, led by **Dr. Satheesh Kumar, MDS**.

Sastha Dental Clinic provides comprehensive dental care with a focus on patient comfort, modern treatment methods, and personalized attention.

## 🏥 Our Branches

Sastha Dental Clinic serves patients through three convenient locations in Chennai:

* 📍 **Kolathur**
* 📍 **Mathur**
* 📍 **Vysarpadi**

## 👨‍⚕️ Dental Care by Dr. Satheesh Kumar, MDS

The clinic is led by **Dr. Satheesh Kumar, MDS**, providing professional dental consultation and treatment for patients of different age groups.

The website is designed to make it easy for patients to:

* Learn about the clinic
* Explore available dental treatments
* Know more about the doctor
* Find the nearest clinic branch
* View clinic contact information
* Book or request an appointment
* Get directions to the clinic
